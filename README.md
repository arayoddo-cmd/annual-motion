# ♈ 별자리 달력 관측소 (지구의 운동 2차시: 공전과 연주 운동)

지구의 **공전**, 태양의 **연주 운동**, **계절별 별자리** 변화를 모형으로 관찰하고 예측하는 수업 자료예요.
교과서 Ⅲ. 태양계 › 2. 지구의 운동 (교과서 240~241쪽·248~251쪽, 학습지 10~12쪽) 내용을 따라가요.

> 시리즈: ① 자전과 일주 운동 (`diurnal-motion`) → ② 공전과 연주 운동 (이 자료) → ③ 달의 위상 변화
> 1차시와 같은 화면 구성·조작법이고, 결과는 같은 구글 시트의 **'연주운동 현황'** 탭에 모여요.

## 화면 두 가지

| 보기 | 보여 주는 것 |
|---|---|
| 🌍 공전 모형 | 가운데 태양, 공전하는 지구, 바깥에 **황도 12궁 별자리 띠** (교과서 그림과 같은 구성). 🔭 비스듬히 / ⬇️ 위에서(북극 위) 보기, 달 버튼(1~12월), +15일·+1달. **☀ 태양 쪽 선**(태양이 지나는 별자리, 낮이라 안 보임), **🌙 한밤중 선**(태양 반대쪽, 한밤중 남쪽 하늘), **✨ 태양의 겉보기 자취**(별자리 사이를 서 → 동으로 이동) |
| 🌇 해가 진 직후 서쪽 하늘 | 8월 사자자리를 날짜별로 보기(8월 1일 → 31일 재생). **겹치기**는 교과서 해 보기처럼 8월 1일·16일·31일 **투명 종이 3장**이 나란히 놓였다가 미끄러져 겹쳐져요. **태양 기준**은 태양이 맞도록 겹쳐서 별자리가 동 → 서(별의 연주 운동), **별자리 기준**은 사자자리가 맞도록 겹쳐서 태양과 지평선이 서 → 동(태양의 연주 운동)으로 보여요. |
| ⚖️ 남쪽 하늘 비교 | 오리온자리를 **같은 날 1시간 간격**(일주 운동)과 **같은 시각(밤 9시) 15일 간격**(연주 운동)으로 봐요. 둘 다 동 → 서이고 같은 자리를 지나지만, 15°를 가는 데 1시간 vs 15일이 걸려요. |

① 탭에서는 +1달을 누를 때마다 지구 위치 **1, 2, 3 …**과 그때 천구(별자리 띠)에 보이는 태양 위치 **1′, 2′, 3′ …**이 표시돼서, 태양이 별자리 사이를 서 → 동으로 옮겨 가는 것(태양의 연주 운동)을 따라갈 수 있어요.
이 탭에서는 띠의 달 글씨를 숨기고 별자리를 배경(천구)으로만 보여 줘요. **🔄 태양 기준** 버튼을 누르면 화면이 지구와 함께 돌아 지구 → 태양 방향이 고정되고, 별자리 하나가 1 → 2 → 3 … 동 → 서로 옮겨 가는 것(별의 연주 운동)이 보여요. 탭 ②에서 "왜 방향이 반대일까?"를 다룬 뒤 돌아와 확인하면 좋아요.

## 👩‍🏫 수업 모드 (TV용)

넓은 화면(TV·노트북, 폭 1000px 이상)에서는 조작 버튼이 **관측 화면 오른쪽 세로 칸**에 모여 있어서 스크롤하지 않고 조작할 수 있어요. 관측 화면은 화면 높이에 맞춰 크게 나와요. (좁은 화면에서는 버튼이 관측 화면 아래에 있어요)

탭 4개: ① 지구의 공전 ② 태양과 별자리의 위치 변화 ③ 황도와 계절별 별자리 ④ 일주 운동 vs 연주 운동.
3D 화면이 크게 나오고, 학습지와 같은 빈칸 정리 카드는 아래에 큰 글씨로 나와요. 빈칸을 누르면 하나씩 답이 보여요. 정리 카드 글씨는 TV에서 멀리서도 읽히게 크게(화면 너비에 따라 28~46px) 나오고, 가려진 빈칸에는 **초성 힌트**(예: 자전축 → ㅈㅈㅊ, 숫자는 ?)가 보여요. 빈칸을 누르면 답이 나와요. 수업 모드에서는 마우스 위치에 **빨간 레이저 포인터 고리**가 따라다니고, 누르면 물결이 퍼져서 학생들이 선생님이 가리키는 곳을 쉽게 찾아요. 가운데 점이 실제로 누르는 자리예요. 왼쪽 아래 **🔴 포인터 켜짐/⚪ 꺼짐** 버튼으로 끄고 켤 수 있어요(브라우저가 기억해요). 정리 카드에는 **학습지 몇 쪽을 쓰는지 초록 배지(📒 학습지 ○쪽)**가 수업 모드 맨 위와 카드 제목 옆에 나와요. 카드의 **흰 글씨는 학습지에 있는 내용**이고, **보라 글씨는 학습지에 없는 더 알아보기**(수업 PPT·교과서에서 더한 내용)라서 학생들이 흰 글씨를 보며 바로 학습지를 채울 수 있어요. 학습지에 없는 탭은 보라 배지(📒 학습지에 없는 더 알아보기)가 나와요.

## 🧑‍🚀 탐사 모드 (학생 태블릿용)

1. **임무 1. 지구의 공전**: 위에서·비스듬히 각각 3달 이상 공전시켜 본 뒤 보고서 6문제 (태양의 연주 운동 뜻·방향·속도를 정리한 설명 상자 포함)
2. **임무 2. 태양과 별자리의 위치 변화**: "8월 31일 사자자리는 어디에?" **예측 → 재생으로 확인**, 겹치기 두 가지를 본 뒤 보고서 6문제
3. **임무 3. 계절별 별자리**: 모형에서 3·6·9·12월의 태양 쪽 별자리와 한밤중 남쪽 하늘 별자리를 찾아 표 채우기(교과서 탐구), 적용 문제 8개(생일 별자리, 염소자리가 보이는 달 등 + 위에서 본 그림에서 **지구 위치 A~D로 몇 월인지·태양이 지나는 별자리·한밤중 별자리 찾기**)
4. **임무 4. 확인 퀴즈**: 형성평가 유형 14문제 (지구 위치 (가)~(라) 그림 문제 2개 포함)

- 임무 3(표를 채운 뒤)과 임무 4에는 펼쳐 볼 수 있는 **💡 별자리 찾기 요령**(태양이 지나는 별자리, 한밤중 = 6개월 뒤 별자리, 지구 위치 그림 읽는 법, 계절별 한밤중 별자리, 달별 별자리 표)이 있어요.
- **통과 기준 임무 1~3은 70%, 임무 4는 60%**: 임무마다 처음 고른 답이 맞은 것이 기준 이상이어야 다음 임무가 열려요. (임무 1: 6문제 중 5개, 임무 2: 예측 1개 + 보고서 6문제 = 7개 중 5개, 임무 3: 표 8칸 + 적용 문제 8개 = 16개 중 12개, 임무 4: 14문제 중 9개) 못 넘으면 해설을 보고 그 임무를 처음부터 다시 풀어요. 재도전 횟수는 시트의 '재도전 (임무 1·2·3·4)' 칸에 기록돼요.
- 모든 학생이 같은 문제를 같은 순서로 풀어요. "하루에 약 1°", "1시간에 15°" 같은 수치는 외울 내용이라 문항에 넣었어요.

## 🎮 마지막 도전 · 지구 컬링 (임무 4를 마치면 열려요)

북극 위에서 본 공전 궤도와 황도 12궁 띠가 나와요. 판을 누른 채 지구에서 멀리 끌었다가 놓으면 지구가 궤도를 따라 미끄러지다 서서히 멈춰요(많이 끌수록 멀리 감).
목표 별자리(노란 칸)에 맞는 달에 지구를 멈추면 성공이에요. **시간 제한이 없어서** 어느 달에 멈춰야 할지 천천히 생각할 수 있어요.

- 지구는 **시계 반대 방향(서 → 동)으로만** 가요. 지나치면 1년을 한 바퀴 더 돌아야 해요. 목표가 끝나도 지구는 그 자리에서 다음 목표를 시작해요.
- 멈추면 **☀ 태양 쪽 선**(그때 태양이 지나는 별자리)과 **🌙 한밤중 선**(한밤중 남쪽 하늘의 별자리)이 띠까지 그려져서 결과를 눈으로 확인해요. 빗나가면 "지금(6월)은 태양이 황소자리를 지나고, 한밤중에는 전갈자리가 보여요" 같은 설명이 나와요.
- 끄는 동안 지구 옆과 세기 막대 옆에 **"약 ○달"**(0.5달 단위)이 보여요. 이동 거리 = 12달 × 세기(끈 길이·화살표 길이에 정비례). 학생은 "몇 달 더 가야 하지?"만 생각하면 돼요.
- 목표마다 5번까지 튕길 수 있어요. 점수 = 정확도(그 달 한가운데 100 ~ 경계 50) + 적게 튕긴 보너스(1번 +50, 2번 +35, 3번 +20, 4번 +10).
- 1단계 태양 길 맞히기("태양이 ○○자리를 지나게!") 2개 → 2단계 한밤중 별자리("한밤중 남쪽 하늘에 ○○자리가 보이게!") 2개 → 3단계 섞어서 2개 + (모두 7개) **내 생일 달에 태양이 지나는 별자리를 한밤중에 보기**(시작할 때 생일 달을 고름, 안 고르면 친구 생일). '탄생 별자리'라는 말은 쓰지 않아요: 점성술 날짜표(예: 4월 하순 황소자리)는 약 2000년 전 기준이라 교과서(4월 물고기자리)와 별자리 하나 정도 차이 나서, 목표 아래와 수업 탭 ③에 짧은 안내를 붙였어요. 목표는 할 때마다 바뀌어요.
- 게임 기록은 임무 성적과 따로 시트의 **'연주운동 게임 현황'** 탭(최고 점수·도전 횟수·마지막 점수·모두 성공·최고 성공률)에 모여요. 교사 화면에 **반 대항 성공률**(학생별 최고 성공률의 반 평균)과 반별 최고 점수가 나와요.
- 🎵 배경음악·효과음은 **게임 화면에서만** 나와요(수업·임무 화면은 조용). 오른쪽 아래 🎵 버튼으로 끌 수 있어요.

- 교사 화면(첫 화면 👩‍🏫 교사용)에서 반별 완료 인원, "한 번에 맞힌 수", 틀린 답(예: "6월 한밤중: 황소자리")을 볼 수 있어요.

## 결과 받기

1차시에서 Apps Script를 새 코드로 바꿨다면 **따로 할 일이 없어요.** 같은 주소로 보내면 시트에 '연주운동 현황' 탭이 저절로 생겨요.
시험: 탐사 모드에서 학번 `00000`으로 들어가면 **선생님 시험 모드**예요. 모든 임무와 게임이 처음부터 열려 있어서 원하는 곳으로 바로 갈 수 있어요. 게임 단계 안내 화면 아래의 **🔧 바로 가기(1·2·3단계)** 버튼으로 앞 단계를 풀지 않고 원하는 단계를 확인할 수 있어요(학생 화면에는 안 보여요). 📋 결과에서 **보내기**를 누르면 시트에 줄이 생기는지 확인할 수 있어요.
